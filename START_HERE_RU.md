# Запуск с твоей папкой Curated

Файлы данных не перемещай и не переименовывай. Код читает original.csv,
blind.csv, a.csv–d.csv и существующие master-матрицы из папок classification
и regression. Обе книги остаются Table1-3.xlsx. Нужен путь именно к Curated.

## Первый шаг — только проверка

Открой терминал в папке encoding-compression-loco и выполни:

```bash
python tools/run_analysis.py --check-data --data-root "ПОЛНЫЙ_ПУТЬ_К_Curated"
```

Для проверки содержимого по хешам добавь --check-hashes. Ожидаются 312
канонических файлов, missing: [] и passed: true. Проверка ничего не обучает,
не перерисовывает и не записывает новые результаты анализа.

## Дальнейший запуск

Сначала сделай рабочую копию Curated: исходные скрипты могут перезаписывать
результаты. Для списка стадий используй --list. Для проверки компиляции:

```bash
python tools/run_analysis.py --analysis classification_01 tg_01 tg_02 tg_03 --data-root "ПОЛНЫЙ_ПУТЬ_К_Curated" --dry-run
```

Команды расчётов находятся в docs/EXECUTION_ORDER.md. Команды для рисунков —
в docs/FIGURES.md; обновлённый код рисунков также выделен в Figures_Code.zip.
Часть рисунков строится из сохранённых CSV, часть исходных скриптов совмещает
обучение и рисование. Это отмечено в инструкции.

Изменены пути, сохранены формулы, параметры и имена оставшихся скриптов.
Два старых самостоятельных Final40-блока и comparator со специально
исключёнными данными убраны из запуска. Точки 40/50 в sweep сохранены.
При этой подготовке новые научные результаты не генерировались.
